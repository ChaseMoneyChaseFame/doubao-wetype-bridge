# 豆微输入法

在豆包输入法与微信输入法之间无缝跳转的 macOS 菜单栏工具。

「豆微」分别取自「豆包输入法」与「微信输入法」。豆微输入法结合了豆包输入法的语音输入能力和微信输入法的日常输入体验：需要语音输入时切换到豆包，语音结束后自动恢复微信输入法。

豆微输入法是输入法切换工具，不是一套独立输入法。它不修改豆包输入法或微信输入法，只负责连接两者的使用流程。

## 功能

- 按下豆包设置的全局语音快捷键时，豆微输入法会提前切换到豆包，减少长时间闲置后的首次等待。
- 豆包输入法的全局语音功能继续负责开始和结束录音。
- 再次按下豆包设置的全局语音快捷键时，结束豆包语音录入。
- 识别豆包输入法的语音录入状态。
- 语音录入结束并等待约 `0.6` 秒后，自动恢复切换前的微信输入法。
- 在菜单栏显示当前运行状态，并提供「立即切回微信输入法」、「开机启动」、「打开运行日志」和「检查更新」等操作。

## 系统要求

- macOS 15.0 或更高版本。
- 已安装豆包输入法和微信输入法，并已在 macOS 键盘设置中启用两者。
- 已在豆包输入法中开启「全局唤起语音」，并设置全局语音快捷键。
- 已允许豆微输入法使用「输入监控」权限。

## 安装与设置

1. 从 [Releases](https://github.com/ChaseMoneyChaseFame/doubao-wetype-bridge/releases/latest) 下载最新版本，将「豆微输入法」拖入「应用程序」。
2. 启动豆微输入法。首次运行时，设置窗口会检查豆包输入法和微信输入法是否就绪。
3. 在豆包输入法的语音设置中开启「全局唤起语音」，设置你常用的全局语音快捷键。
4. 在豆微输入法设置中点击「授权」，允许「输入监控」。
5. 按需开启「开机启动」。

## 使用方法

1. 将当前输入法设为微信输入法。
2. 第一次按下豆包设置的全局语音快捷键，豆微输入法会先切换到豆包，豆包随后开始语音录入。
3. 语音输入完成后，再次按下该快捷键结束录入。
4. 豆包停止使用音频输入并等待约 `0.6` 秒后，豆微输入法会自动切回开始语音输入前使用的微信输入法。

如果自动恢复失败，可在菜单栏菜单中选择「立即切回微信输入法」。

## 隐私

豆微输入法全程在本地运行，不设置服务器，不收集、上传或销售用户数据。

- 应用不请求麦克风权限，不录制音频，只读取 macOS CoreAudio 提供的豆包输入法音频输入使用状态。
- 运行日志保存在 `~/Library/Logs/DoubaoWeTypeBridge/runtime.log`，不包含输入文字或语音内容。

完整说明见 [PRIVACY.md](PRIVACY.md)。

## 本地构建

需要安装 Xcode Command Line Tools。

```bash
swift run BridgeSelfTests
./Scripts/build-app.sh
```

构建完成后，应用位于 `.build/product/豆微输入法.app`。如需生成 DMG，运行：

```bash
./Scripts/create-dmg.sh
```
